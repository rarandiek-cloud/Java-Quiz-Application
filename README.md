# Java Quiz Application

## Project Overview

The Java Quiz Application is a console-based program developed using Java. It allows users to test their knowledge of fundamental Java programming concepts through multiple-choice questions.

The application uses reusable methods and separate classes to organise the different quiz topics.

## Quiz Topics

The application includes five quiz categories:

1. **Arrays** – Tests understanding of arrays and how they are used in Java.
2. **Loops** – Covers `for` loops, `while` loops and iteration.
3. **Conditional Statements** – Tests the use of `if`, `else if` and `else` statements.
4. **Functions and Methods** – Covers methods, parameters and return values.
5. **Object-Oriented Programming (OOP)** – Introduces fundamental OOP concepts.

## Project Structure

The project is organised into the following Java classes:

| File | Description |
|---|---|
| `Main.java` | Displays the main menu and allows users to select a quiz topic. |
| `Quiz.java` | Contains the reusable `runQuiz()` method used by all quiz categories. |
| `ArrayQuiz.java` | Contains questions about arrays. |
| `LoopsQuiz.java` | Contains questions about loops. |
| `ConditionalQuiz.java` | Contains questions about conditional statements. |
| `MethodsQuiz.java` | Contains questions about functions and methods. |
| `OOPQuiz.java` | Contains questions about object-oriented programming. |

## Features

- Interactive console-based menu.
- Five programming quiz categories.
- Multiple-choice questions.
- Reusable quiz logic to reduce code duplication.
- Automatic answer checking.
- Score tracking showing the total correct answers.

## Technologies Used

- Java
- IntelliJ IDEA
- Git and GitHub

## How to Run the Application

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure a Java JDK is configured.
4. Open `Main.java`.
5. Run the `main()` method.
6. Follow the menu instructions and select a quiz category.

## Learning Objectives

This project was developed to practise fundamental Java programming concepts, including:

- Arrays and loops.
- Conditional statements.
- Methods and reusable code.
- Object-oriented programming.
- Classes and code organisation.
- User input using the `Scanner` class.
